# Kaisas Lernwelt

Browserbasierter Mathe-Prototyp für Kaisa (4. Klasse).

Enthalten sind sechs Missionen im dunklen K-Pop-Demon-Hunter-Stil:

1. Längen-Scan
2. Längen-Mix
3. Liquid-Flow
4. Gewichts-Boost
5. Küchen-Chroniken (Sachaufgaben)
6. Schatten-Boss (gemischt)

Der Lernfortschritt wird ohne Login lokal im Browser gespeichert.

Für eine lokale Vorschau kann im Projektordner `node preview-server.cjs` gestartet und anschließend `http://127.0.0.1:8000` geöffnet werden.
